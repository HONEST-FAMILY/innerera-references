## 4. 빌려온 것 — Function Health · Superpower (보드 녹화 function.mp4 / superpower.mp4, 1.5fps 시트로 확인)
- Function Health(12.0s): 영화 같은 사진 첫 화면 + **오른쪽 아래 사실 3칸 줄**(160+ lab tests / Whole body / $1 per day, 굵은 짧은 값 + 작은 설명). t≈6.5s 첫 화면 안에서 사진이 마스크로 다음 장면으로 바뀜.
- Superpower(12.0s): 검정 첫 화면 + 왼쪽 큰 제목 + **아래 사실 3칸**(가는 글자), 내리면 흰 판이 올라옴.
- → 4안: 첫 화면 오른쪽 아래 사실 3칸(5가지 핵심 원료 / 20 g × 14포 / 석류맛, 위 1px 선) — 제목과 같은 마스크 상승으로 0.5s~0.66s에 차례로 등장. 폭 1100 이하에선 숨김(글 줄이기).
- 안 가져온 것: Superpower의 주황 팝업, Function의 영상(우리 소재는 사진뿐), Seed 마케팅 팝업.

## 7. 디자인 검수 — 문제 → 고친 방법
1. PC 첫 화면 제목이 석류에 겹침 → 사진을 오른쪽 정렬(right -14vw, 1024는 -26vw) + 왼쪽 24% 마스크로 검정에 녹임.
2. 폰 첫 화면: 사진을 꽉 채우니 흰 글자가 붉은 과육 위에 얹힘 → 사진을 폭 맞춤으로 위에 두고 글은 아래 검정 위로, 사진 아래 경계는 마스크로 녹임.
3. 1024 제품 장면: 상자 아래가 탭바에 잘림(격자 줄이 원본 그림 높이 1242px로 늘어남) → 줄을 minmax(0,1fr) + min-height 0.
4. 폰 원료 장면: 출처 문구가 목록 칸과 겹침 → 4번째 줄로 분리.
5. 폰: 스틱이 나오는 도중 화면 밖으로 잘림·궤도 고리 양끝 잘림 → 상자+스틱 묶음을 -14% 옮기고 스틱 이동폭 0.86→0.8, 1024 이하 고리 폭 100%.
6. 원료가 넘어갈 때 두 이름이 겹쳐 보임 → 나가는 글 0.2s로 빨리 빼고 들어오는 글 0.22s 뒤에 올림.
7. 5→1 장면: 숫자 1인데 설명이 '따로 챙기던 원료' → 1이 되는 순간 '하루 한 포'로 바뀌게.
8. 움직임 줄이기: 원료 칸이 그래도 움직임(선택자 우선순위) → !important로 정지 / 리추얼 사진 늦게 불러와 빈칸 → 바로 불러오기.
9. favicon 404 → data: 아이콘.
