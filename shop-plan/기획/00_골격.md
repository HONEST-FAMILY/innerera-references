# 범용 쇼핑몰 솔루션 기획 골격 (이슈 #1874, 2026-11-11)

이 문서는 기획서·기능정의서·와이어프레임이 함께 따르는 약속이다. 화면 번호(U-xx, A-xx)와 화면 상태 목록은 와이어프레임 사이트맵과 1:1로 맞춘다. 기획서를 쓰다 화면을 더하거나 빼야 하면 이 문서부터 고친다.

## 0. 한 줄 정의
어니스트패밀리가 쇼핑몰 의뢰가 들어올 때마다 다시 쓰는 **자체 쇼핑몰 솔루션**. 1호 적용은 이너에라(Inner:Era) 공식몰. 고객사 운영자가 개발자 없이 상품·주문·배송·고객응대·전시·설정을 처리하고, 카페24·스마트스토어 판매자센터에서 일하던 실무자가 처음 봐도 바로 쓸 수 있는 관리자.

## 4. 주문 상태 (품목 주문 단위 — 한 주문 안 품목마다 따로 움직인다)
입금대기 → 결제완료 → 배송준비(발주확인) → 배송중 → 배송완료 → 구매확정
클레임: 취소요청 → 취소완료 / 반품요청 → 수거중 → 수거완료(검수) → 반품완료(환불) / 교환요청 → 수거중 → 재발송(배송중) → 교환완료 / 각 요청은 거부 가능(사유 필수, 원래 상태로)
결제완료 단계 취소는 고객이 바로 취소(승인 없이 자동 환불), 배송준비부터는 취소 요청 → 운영자 승인.
